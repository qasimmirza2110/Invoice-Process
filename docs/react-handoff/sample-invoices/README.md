# Sample invoice PDFs (synthetic)

Six small, **made-up** one-page invoices (`synthetic-sample-invoice-01.pdf` … `-06.pdf`, invoice numbers
`DEMO-0001` … `DEMO-0006`) for trying the vendor upload screen while you build it.

- They are **examples only**. The API accepts **any valid invoice PDF** up to 10 MB — there is no list of allowed
  files. Real vendors upload their real invoices.
- Each vendor account can upload the same file only **once** (the normal per-vendor `DUPLICATE_FILE` rule).
  To try again, log in as another vendor or use another sample.
- Never put a real invoice in this folder, in Git, in screenshots or in a Postman export.
